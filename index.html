About Melops/OS/

Melops is a free and open-source 32-bit Operating System written in the C programming language.
At the moment, it's a text-based operating system like DOS. This is a hobby project written with too much free time.

Why Melops?

If you're interested in low-level programming or kernel dev, you are welcome to optimize, reconfigure, or make your own operating system.
"Melops" comes from the first syllables of the scientific term for a budgie (Melopsittacus).

About The Developer

I like programming in C and have tried making operating systems before. I was fascinated by Linux.
Yes, I am a Fedora Linux user, but I don't live the cliche Linux programmer lifestyle!
My previous anonymous OS used primitive techniques like BIOS legacy USB input, which meant my CPU was always at 100% because I didn't include a GDT and IDT.
This time with Melops/OS/, I am doing it the right way. I have already implemented key features like a terminal runtime with interrupts on point, along with some cool string features.
